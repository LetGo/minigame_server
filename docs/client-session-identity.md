# 客户端实例与登录会话关联

## 协议与用途

登录请求新增可选 `clientInstanceId`，只接受 UUID v4；省略兼容旧客户端，显式 null 或非法格式返回 400。客户端首次登录生成随机 UUID，使用 PlayerPrefs 持久保存，后续启动复用。清除本地数据后可能变化，它不是永久硬件身份，也不是鉴权依据。

每次成功登录由服务端生成新的 `sessionId`，与实例标识一同写入 Redis 会话和登录事件。登录成功响应保持原协议，不暴露 token 的摘要或将 token 当作日志标识。激励视频上报只从已鉴权会话取得两个字段，客户端无需修改广告请求；跨会话重试沿用原 eventId 时保持首次入库归属与既有去重语义，不新增记录。

后台登录日志、广告日志新增实例 ID 与会话 ID 两列，历史事件和旧会话没有字段时显示“未知”。实例不同可以证明上报来自不同本地实例，不能单凭登录时间证明同时在线或实际硬件不同。

## 云档读写追踪

新增 `game_save_access_events`，记录成功 get/save 的应用、用户、操作、实际版本、实例、会话和数据库时间，不记录存档正文或令牌。读档首次无档记录版本 0；保存及其成功审计在同一 SQL 语句中原子执行，版本冲突不产生成功写入事件。失败请求暂无单独审计事件。此表本轮用于数据库排查，未新增后台云档日志页面。

这不会改变存档冲突策略、每日奖励额度或启动读档顺序，也不包含心跳和在线状态判断。本地来源云档版本及自动同步另行实施。

## 发布顺序与权限

1. 使用数据库迁移身份执行 `016_client_session_identity.sql`（通过既有迁移命令），先迁移后发布服务代码与后台。
2. 正式运行角色需增加 `GRANT INSERT ON game_save_access_events TO minigame_app;`，测试环境对应 `minigame_staging_app`；既有登录、广告表扩列沿用原表级权限。
3. 如后台只读角色需要直接查询云档审计，单独授予 `GRANT SELECT ON game_save_access_events TO minigame_dashboard_app;`。现有页面不依赖该权限。
4. 发布客户端新包后才会收到实例 ID；服务端新版本启用后，旧客户端新登录也可获得服务端会话标识。原有存量会话不追溯补造。

日志随用户删除级联清理；日常保留与归档周期应按运维存储需求确定。

## 验证

增加不同实例同账号登录、广告跨会话幂等、无效实例拒绝、云档实际读写版本及冲突审计测试，更新后台列数与身份字段回归。测试使用隔离 PostgreSQL 15439 和 Redis 16389/15，禁止对正式库运行测试。客户端验证与限制见 Unity 工程专题文档。

验证结果：Node 24 环境下类型检查、构建及 48 项基础测试通过；220 项后台测试通过；登录、云档、广告与后台查询合计 41 项集成测试通过。集成测试在本次独立数据库 minigame_identity_20261112 上运行，不使用正式数据库。本地 Node 22 安装依赖失败，因此以上服务端验证在远端独立临时目录完成，未替换运行中的服务。

## 设备信息拼接调整

新版 clientInstanceId 使用 `UUID_平台_品牌_型号`，示例 `12345678-1234-4234-8234-123456789abc_ios_apple_iphone15,2`。客户端调用微信 GetDeviceInfo，各设备段转小写，只保留英文字母、数字、点、逗号、加号、短横线，其他字符替换为短横线；每段最多 40 字符，空值使用 unknown。首次生成后整体持久保存；旧本地 UUID 首次升级时保留 UUID 前缀并追加设备信息，不随以后机型信息变化重建。

服务端兼容旧纯 UUID 和新拼接字符串，sessionId 仍为独立 UUID，无新增业务字段。上线先执行迁移 017，将三处实例列从 uuid 扩展为 varchar(159)，再发布代码；迁移 016 不修改，保留已执行校验和与旧记录。设备名称仅供排查，不能视为可信硬件身份。

设备拼接版本验证：类型检查、构建、48 项基础测试通过；220 项后台测试通过；专项集成测试最终全部通过（原 41 项中登录日志两项在修正历史兼容查询类型后通过，另重跑后台查询共 9 项全部通过）。客户端真实 SDK 编译及设备异常、旧 UUID 升级专项通过。未部署生产。

## 上线前兼容范围修正

用户确认尚未上线，最终协议仅接受 UUID_平台_品牌_型号，纯 UUID 返回 400；客户端无效缓存直接重新生成，不保留旧 UUID 前缀。此前关于纯 UUID 兼容及保留前缀的说明不再适用。字段省略仍沿用现有登录协议，不强制已发布的其他客户端更新。迁移文件保留版本演进顺序，数据库类型转换不是接口格式兼容。
