# 登录请求：客户端游戏版本（正式服、测试服均已部署）

> 状态：测试服已于 **2026-10-23 12:38:59** 部署；正式服已于 **2026-10-23 18:14** 发布完成并通过验收（均为北京时间）。两环境均可发送可选 `clientVersion`；**旧客户端仍可只传 `code`，不要求升级。**

## 请求地址

- 测试服（已支持）：`POST https://sub2api.wdaveh5game.com/h5login-test/api/auth/wechat-login`
- 正式服（已支持）：`POST https://sub2api.wdaveh5game.com/h5login/api/auth/wechat-login`
- 请求头：`Content-Type: application/json`

```json
{
  "code": "wx.login() 返回的新鲜 code",
  "clientVersion": "1.2.3"
}
```

`code` 的要求不变。新增字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `clientVersion` | string | 否 | 当前游戏包/资源版本，由客户端上报，不是微信版本、基础库版本或存档 CAS 版本 |

版本格式：1–64 个 ASCII 字符，以英文字母或数字开头，其余只能是英文字母、数字、`.`、`_`、`+`、`-`。不强制语义化版本；例如 `1.2.3`、`1.2.3-beta.1`、`20261023_1` 均可。

- 旧客户端继续只传 `{ "code": "..." }`，仍可正常登录。
- 不知道版本时省略 `clientVersion`，不要发送空字符串或 `null`。
- 不接受数字、空白、换行、中文、数组、对象或超长版本；不自动去掉首尾空白。无效请求返回 HTTP 400，且不会调用微信换码。
- 不接受 `userId`、`openid`、`appId` 等额外身份字段。
- 版本字符串原样保存，不排序比较、不强制升级、不阻止旧版本登录。

## 记录口径

- 登录成功时，事务内写入当前用户 `game_users.last_client_version`。
- 后续成功登录携带版本时更新；不携带版本时保留已有值。
- 从未上报的用户为数据库 `NULL`，历史用户不会被推测或补造版本。
- 记录的是最近一次**成功登录且携带版本**的上报；不是所有登录事件历史，也不能断言用户此刻仍运行该版本。
- 微信换码、数据库或会话创建失败时，不提交本次版本变更。
- 版本来自客户端自报，不是微信认证信息，不能单独用于安全授权或防作弊判断。
- 版本上报不更改登录响应、存档或会话协议；最初该次发布未增加看板列，后续2026-10-23 20:15已发布登录日志版本列。它仍读取最近成功上报版本，不是事件时点快照，见 [dashboard.md](dashboard.md)。

## 客户端示例

```js
// GAME_VERSION 由打包/发布流程维护为真实游戏版本。
const GAME_VERSION = '2.0.7';

wx.login({
  success({ code }) {
    if (!code) return;
    wx.request({
      url: 'https://sub2api.wdaveh5game.com/h5login/api/auth/wechat-login',
      method: 'POST',
      header: { 'content-type': 'application/json' },
      data: { code, clientVersion: GAME_VERSION },
      timeout: 20000,
      success(res) {
        // 沿用现有 HTTP 状态检查、token 保存及登录处理；不要打印 token。
      },
      fail(err) {
        // 沿用现有网络错误处理，不自动复用一次性 code 重试。
      }
    });
  }
});
```
